# MyBlog Android

مشروع تحويل MyBlog إلى تطبيق Android يعمل محلياً دون إنترنت، مع إمكانية فتح نسخة الموقع المتصلة بالإنترنت.

## بناء APK عبر GitHub Actions

1. ارفع محتويات مجلد المشروع إلى جذر هذا المستودع، بحيث يكون مجلد `android-app` بجانب مجلد `.github`.
2. افتح تبويب **Actions**.
3. اختر **Build MyBlog Android APK** ثم **Run workflow** (أو انتظر التشغيل التلقائي بعد رفع ملفات android-app).
4. بعد نجاح البناء، افتح نتيجة التشغيل ثم قسم **Artifacts** وحمّل `MyBlog-debug-apk`.
5. فك ضغط ملف Artifact وثبّت `app-debug.apk` على هاتف Android.

## ملاحظات

- لا ترفع `database.db` إلى مستودع عام؛ فهو يحتوي بيانات حساب الإدارة.
- لا ترفع مجلدات `__pycache__`.
- يجب أن تكون بنية المستودع هكذا:
  - `android-app/`
  - `.github/workflows/android.yml`
  - `app.py` (اختياري لتشغيل نسخة Flask)
  - `templates/` و `static/` و `schema.sql` (لنسخة Flask)

التطبيق المحلي يحتفظ بمقالاته على الهاتف. إعداد عنوان الموقع يفتح النسخة البعيدة فقط؛ لا توجد مزامنة تلقائية ثنائية الاتجاه بين البيانات المحلية والخادم في هذه النسخة.
